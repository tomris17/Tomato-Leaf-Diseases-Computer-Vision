This repository contains the dataset directory structure setup and exploratory pipeline for training and evaluating a tomato leaf disease detection model using train, validation, and test split datasets[cite: 17].

---

## Dataset Notice
*Note: The dataset used in this project[cite: 17] follows a standard object detection / image classification directory structure (`train/`, `valid/`, `test/`) with corresponding image and label subdirectories.*

---

## Project Workflow
1. **Directory Structure Verification**: Setting up paths for train, validation, and test image directories[cite: 17].
2. **Data Inspection**: Counting available training samples and verifying image integrity[cite: 17].
3. **Visualization**: Reading sample images via OpenCV and plotting them using Matplotlib[cite: 17].
4. **Web Application**: Interactive deployment interface built with Streamlit.
